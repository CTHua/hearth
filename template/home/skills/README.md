# Skills

可重用、按需載入的操作知識：一件會重複做的事，寫成工程師或 agent 照著做都能完成的步驟。

## 怎麼找、怎麼用

- 一個 skill 一個目錄：`skills/<name>/SKILL.md`。它用到的腳本或範例檔放同一個目錄。
- 列出有哪些 skill 和各自的適用情境：

  ```sh
  grep -H '^description:' skills/*/SKILL.md
  ```

- 任務符合某個 skill 的適用情境時才讀全文，不預先全部讀。
- 不要假設工具會自動發現這個目錄。入口是 `AGENTS.md` 的目錄導覽，需要時照路徑自己去讀。
- 這個目錄的 skill 不會被安裝或 symlink 到任何工具的自動載入位置。要接過去，由團隊自己決定並開 PR。
- 目錄名以 `_` 開頭的是模板。

## 每個 skill 要寫明

| 段落 | 內容 |
| --- | --- |
| 適用情境 | 什麼任務該用，什麼時候不該用 |
| 前置條件 | 需要的工具、權限，以及要在哪個 repo、什麼狀態下開始 |
| 步驟 | 編號步驟，一步一個動作，指令寫完整 |
| 驗證方式 | 怎麼確認做對了：要跑的指令和預期結果 |

## 怎麼新增

1. 複製 `skills/_template/` 成 `skills/<name>/`，`<name>` 用 kebab-case。
2. 填 frontmatter：`name` 和目錄同名，`description` 用一行寫適用情境。
3. 照寫好的步驟實際做一次，確認驗證方式會過。
4. 開 PR。

## 不放這裡的

- 只適用單一產品的操作：放那個產品的 repo。
- 秘密、憑證、token。步驟需要憑證時，寫去哪裡取得，不寫值。
